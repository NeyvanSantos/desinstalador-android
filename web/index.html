Arquitetura & Segurança

Como funciona por baixo do capô?

Transparência total. Sem truques ocultos, sem permissão de internet e com código 100% auditável: 

class BatchUninstallService : AccessibilityService() {

    // Timeout de segurança (Fail-Closed): desativa se a fila for pausada
    private val watchdogTimer = Timeout(seconds = 15)

    override fun onAccessibilityEvent(event: AccessibilityEvent) {
        // Proteção anti-tapjacking: rejeita cliques obscuros
        if (event.isObscured) return

        // Localiza o botão nativo de confirmação ("OK" ou "Desinstalar")
        val confirmBtn = rootInActiveWindow?.findAccessibilityNodeInfosByViewId(
            "android:id/button1"
        )?.firstOrNull()

        confirmBtn?.performAction(AccessibilityNodeInfo.ACTION_CLICK)
        watchdogTimer.reset()
    }
}

object SystemProtectionWhitelist {
    // Pacotes que NUNCA podem ser desinstalados para evitar brick
    val PROTECTED_PACKAGES = setOf(
        "com.android.vending",          // Google Play Store
        "com.google.android.webview",  // Android System WebView
        "com.android.settings",        // Ajustes do Sistema
        "com.miui.home",               // Launcher Xiaomi
        "com.sec.android.app.launcher" // Launcher Samsung One UI
    )

    fun isSafeToUninstall(packageName: String): Boolean {
        return packageName !in PROTECTED_PACKAGES
    }
}

Dúvidas Frequentes

Precisa de computador, cabo ou Root?

Não. O aplicativo opera diretamente no próprio smartphone através da API nativa de acessibilidade do Android, dispensando Shizuku, comandos ADB ou root.

Existe risco de excluir apps vitais do sistema?

Não. A whitelist de segurança nativa do aplicativo bloqueia a exclusão de componentes essenciais como Google Play Store, Ajustes, WebView e o Launcher do fabricante.

Como instalar o arquivo APK?

Após o download, toque na notificação do arquivo baixado. Se o Android solicitar permissão para "Fontes desconhecidas" no seu navegador, autorize a instalação e conclua em segundos.
